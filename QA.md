## Фактические проверки

- `node tools/verify.mjs`: 438 проверок структуры, front matter, категорий, типов полей, путей, CMS-подсказок, WebP и основных контрастов.
- `node --check`: прикладные JS-модули и admin/admin.js; синтаксических ошибок нет.
- `git diff --check`: ошибок форматирования нет.
- Браузер: 36 сочетаний страницы и ширины, один h1 и отсутствие горизонтального переполнения; у контентных изображений есть alt, размеры и loading="lazy".
- Точная ширина 768 CSS px дополнительно проверена в изолированных фреймах из-за округления масштаба Windows в окне браузера.
- Поиск «ПАСТА» возвращает одно блюдо, незнакомый запрос показывает пустое состояние; «ризотто» показывает пометку недоступности.
- Мобильное меню: открытие, Esc и фактический клик по затемнённой области вне меню.
- События на дату проверки: 5 ближайших и 2 прошедших. Ноябрь открывается стрелкой; 24 октября выбирается один гастрономический ужин; сброс даты возвращает выбранный период.
- Журнал: «Кухня» — 2 статьи, «Атмосфера» — 1; открытие статьи и соседние ссылки работают.
- Галерея: открытие изображения в dialog и закрытие Esc.
- Открыты все 7 событий и 4 статьи; неизвестные slug корректно обработаны.
- В консоли браузера при проверке посетительских страниц ошибок и предупреждений не обнаружено.
- Админка загрузила конфигурацию и показала кнопку «Войти через GitHub» без ошибки конфигурации. Вход и удалённое сохранение не выполнялись.

## Ограничения и условия передачи

- Это вымышленный ресторан; фотографии, контакты и афиша требуют замены перед настоящим запуском.
- Проверены размеры в браузере; отдельная проверка на физическом телефоне остаётся за заказчиком.
- Для новых записей на публичных Pages используется GitHub API с двухминутным кешем и резервным файловым индексом. При ограничении API новые записи появляются после обновления индекса; порядок описан в README.
- SEO метаданные отдельных событий и статей уточняются JavaScript; серверного предварительного рендеринга нет, как и требуется для buildless-проекта.
- Публичный URL и реальное OAuth-сохранение до их подключения не считаются проверенными.
